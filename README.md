# Smart Interview Assistant

An AI-powered interview preparation platform that analyzes resumes, extracts skills, and generates role-specific interview questions.

## Features

* Resume Upload (PDF)
* Skill Extraction from Resume
* AI-generated Interview Questions
* Role-based Question Generation
* Interactive Answer Submission UI
* FastAPI Backend
* Next.js Frontend

## Tech Stack

* Python
* FastAPI
* Next.js
* React
* SQLite
* Render
* GitHub

## Project Architecture

Resume Upload → Resume Parsing → Skill Extraction → Question Generation → User Response Interface
